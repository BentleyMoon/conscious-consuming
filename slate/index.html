Turn what a group cares about into a plan, with a reason on every line

Load the full group export from group values and a facts file. This page lists what the group would use and what it would move away from, gives each line the fact behind it, and prints what the group split on above the list. It is a suggestion with its working shown. The group still decides, and nothing is uploaded.

The two files

It opens with the four people from the group values example (Ada, Ben, Cy and Dee) and the demo facts file for messengers. Swap either one for your own.

Plate IIFig. 2. What the group would use and move away from, with the reason for each line.

The plan

Load your own values file in place of the group’s and count how many lines change. Each line that changes is a choice where your values and the group’s give different answers.

What’s happening. The group’s weights, 0 to 5, are applied to each option’s facts, which are scored 0 to 100. The top three options that score 60 or more go on the use list. An option goes on the move-away list only when it scores 25 or less on something the group weighted 4 or more, and that line names the fact.

Why it matters. Without a reason on each line, nobody can tell which fact it depends on. With the reason printed, anyone in the group can point at the exact fact they doubt, and the saved plan carries the facts file’s fingerprint, so a later reader can check it against the same facts.

Devil’s advocate. The example facts are the Where to Message demo file, which covers seven messengers and whose own header says the scores are illustrative and are not an audit. None of its facts has a source link, so every line here says so. The app’s real messaging comparison has 19 apps with a source for every fact, and the tour runs on it. The plan also has no idea what anyone already uses; it will tell a group to move away from iMessage whether or not half of them own iPhones.

Rabbit hole. Change a fact in fact repair, save your own facts file, load it here with Load a different facts file, and watch the plan and its fingerprint change.

How the files move

  1. In: the full group export from group values, which holds the group’s average weights and what it split on. One person’s values file works too.
  2. In: a facts file, a list of options with a score and a note for each fact. The demo file loads by default; fact repair saves others.
  3. Out: a plan file with every line, its reason, the splits and the facts file’s fingerprint. Nothing is uploaded at any step. How file-sharing works.

What the plan must keep visible

  • Each line keeps its reason: the measure, the score, the note behind it, and the source whenever the facts file has one.
  • What the group split on is printed above the plan, so what most of the group wants is not mistaken for what everyone wants.
  • The group still chooses what to adopt. The page only works out what the files say.
  • A fact you think is wrong can be fixed by changing it in fact repair, saving your own facts file and loading it here.
