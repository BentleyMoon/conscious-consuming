Group valuesSeveral values files, added up in your browser.

See where your group agrees, and where it splits

Each person brings the small file their app saved. It holds how much they care about each value, from 0 to 5, and no name. This page adds the files up in your browser and puts every person's weights beside the group's. Nothing is uploaded, and anyone holding the same files gets the same table.

Bring the files

Two files are enough to see a split. The label beside each file comes from its filename or from the app that made it, and you can change it. The full group export lists these labels, so use whatever the group is happy to have written down.

or drop them here. They are read on this device and go nowhere else.

A values file comes from Conscious Consuming, Kosplora, Where to Message or step 1 of the tour. It holds weights and nothing that says who you are. What a values file carries.

No files to hand? Load the example group and look at the Autonomy row before anything else.

What’s happening. Each row is one value. The numbers are each person’s weight, 0 to 5, and the Together column is their average. The word at the end says how far apart they are, from the spread of their weights: aligned when the spread is 0.75 or less, split when it is more than 1.25, mixed in between. A value someone’s file leaves out is left out of that row for them; it does not count as a 0.

Why it matters. An average on its own makes every group look as if it mostly agrees. The split rows are what the group needs to talk about, and the full group export carries them to the shared plan, which prints them above its list.

Devil’s advocate. In the example, Ada and Cy put Autonomy at 5 and Ben and Dee put it at 1. The average is 3.0, a number none of the four chose, which is why the row is hatched and not trusted. The page also takes every file on trust: it cannot tell whether Ben’s file was made by Ben, and anyone can edit one in a text editor. Use it with people you already trust. It counts files, and it has no idea how many people are behind them.

Rabbit hole. How the files travel between people and apps with no server in the middle is written up in how file-sharing works.

How the files move

  1. Each person saves a values file from an app that writes one.
  2. They hand it to whoever is running this page, any way they like: email, a chat, a USB stick. This page sends nothing anywhere.
  3. The files go in above. The group’s result can be saved as a file, either the group’s values on their own or the full group export, which also carries who split on what.
  4. The full group export goes into the shared plan, where the group’s values are applied to the facts about real options.

Group values and the shared plan are one of two pairs of group tools in this family. In the other pair, the Work Party reads positions written on the Socratic Hearth. The two pairs do not read each other’s files yet. See where each group file goes.

What this page promises

  • People bring their own files. Nobody’s values are guessed, looked up or collected from anywhere else.
  • The adding up happens in this browser and uploads nothing. You can check by opening your browser’s network panel and dropping a file in.
  • Where people split stays on the page, next to where they agree. A split value is never folded into the average without a mark on it.
  • Full group export is the file to take to the shared plan. It holds each value’s average, its spread, how many files gave it a weight, and the list of splits.
