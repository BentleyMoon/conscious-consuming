For builders

Open Values Standard

This is the builder-facing specification for the files Values Commons passes around: what someone values, what the sourced facts say, how rankings are re-run, how a group finds agreement, and how a plan stays accountable. The aim is permissionless compatibility between tools.

The shape

Small files, reproducible decisions

The standard is not a social network or a ranking authority. It is a grammar for decisions that can be inspected, repaired, combined, and re-run from files.

Values

Values file

A local, nameless file of weights and deal-breakers that says what matters to a person or group.

Facts

Sourced facts

A roster of options, criteria, scores, notes, links, and dates. It can be corrected or kept as a separate version.

Decision

Ranking

A deterministic result from values plus facts. Same inputs, same order, with withheld confidence when facts are thin.

Together

Group agreement

Many values files combined into a shared stance that preserves disagreement instead of smoothing it away.

Action

Shared plan

A derived list of buys, avoids, switches, or priorities with the reason and evidence attached.

Apps

Compatible app

A subject-specific front end running the shared shell and engine with its own facts, look, and language.

Conformance v0.1

What counts as standard-aligned

A project can be creative in its domain and design, but the core promise should stay recognizable.

Local-first core. Values and rankings work without an account or server dependency.
No pay-to-rank. Money cannot buy placement inside a values-relative ranking.
Portable values. A user can export and import values without identity baggage.
Sourced claims. Assessed facts carry sources, dates, and a human-readable basis.
Repairable facts. Disagreement creates a visible patch or alternate file that anyone can inspect.
Reproducible results. Rankings can be re-derived from the same public inputs.

The spec versus the public site

Open Values Standard is the protocol. Values Commons is the public site built on it. Conscious Consuming is the first flagship app proving that the protocol can carry real, sourced decisions.

That is why openvaluesstandard.org is best used as the spec home or redirect to this page, while valuescommons.org carries the public story.
