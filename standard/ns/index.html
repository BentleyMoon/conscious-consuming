The ovs: namespace

Linked data on the comparison pages uses schema.org terms where one fits, and terms under https://openvaluesstandard.org/ns# where none does. This page defines each of those terms.

Relations

TermUsed forMeaning
ovs:suppliessuppliesThe subject supplies goods or services to the object.
ovs:certifiedBycertified-byThe subject holds a certification issued by the object.
ovs:analogousToanalogous-toThe subject plays the same role as the object in a different decision.
ovs:inDomainin-domainThe subject belongs to the area of everyday life named by the object.

The balanced score

ovs:verdict is a schema.org PropertyValue holding the plain fit label an option gets when every value is weighted equally. It is not a recommendation; the app ranks by each reader's own weights.

Identifiers

An option is identified as ovs:<decision>/<code>, for example ovs:banking/triodos, and a brand as ovs:brand/<name>. These are names, not addresses; the page for an option is at https://valuescommons.org/app/c/<decision>/<code>.

Generated from the registry, the schemas and the conformance examples, so it matches them exactly.
