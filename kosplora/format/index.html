The route file format.

kosplora-route/0.1 · published 2026-08-18 · any change will appear here, dated

A route is one text file. This page is the whole specification: what the file holds, what makes it valid, and a blank one to copy.

What a route file holds

A question worth following. The move it makes: understand, decide, make, practice, teach or organize. A stated time. Three to nine stations, each with a type, a task and its sources. What you leave with, and the ways out. Two more fields ask the author to be honest about the route:

would_change
What would make the author restructure the route. A route whose author cannot name one is not open to correction.

Eight station types

orientGet your bearings from something with visible provenance.
sourceRead, watch or examine one thing closely.
counterpointMeet a credible disagreement from outside the route.
personSpeak with someone.
placeGo somewhere real.
practiceAttempt the skill.
makeProduce the thing you keep.
reflectClose the route and say what changed.

The first version of this page called them seven and then listed eight. It is eight. The list is closed. A new type needs a new version of the format, so a copied route still works in someone else's walker, the program that shows a route.

What makes a file valid

  1. It parses, and its format field names a version a walker knows.
  2. It has three to nine stations. At least one can correct the person walking it (a counterpoint, a person with a different relationship to the question, or a tested practice), and at least one happens away from the page (a person, a place, a practice or a making).
  3. Every counterpoint cites at least one source whose origin is a published work, a person or a dataset, with an author and a date. An objection written by whatever drafted the route does not count. Legible AI has the measurements behind this rule. A second opinion adds information only when it comes from a different source, and asking the same model a second time gets the same opinion twice.
  4. Every source carries a date, or the walker prints "undated" beside it.
  5. would_change is present and not empty.
  6. A file with no correcting station or no active station is still valid, but only as kind: reading-list, and a walker titles it that way. The reading shelf takes its name from this rule.

A starter file

Copy it, fill it in any text editor, and put it beside one of the walkable routes to compare. Each of those has its own route.json one click from its page.

{
 "kind": "route",
 "format": "kosplora-route/0.1",
 "question": "",
 "move": ["understand"],
 "audience": "",
 "time": { "solo": "2h" },
 "authors": [{ "name": "", "date": "" }],
 "would_change": "",
 "stations": [
  { "type": "orient", "time": "30m", "task": "",
    "sources": [{ "title": "", "author": "", "date": "", "url": "", "origin": "published" }] },
  { "type": "person", "time": "40m", "task": "" },
  { "type": "counterpoint", "time": "20m", "task": "",
    "sources": [{ "title": "", "author": "", "date": "", "origin": "published" }] },
  { "type": "make", "time": "45m", "task": "" }
 ],
 "artifact": { "keeps": "" },
 "exit": ["keep", "share", "fork", "close"],
 "revisions": [{ "date": "", "change": "First version.", "by": "" }]
}

What's happening. This is everything a route needs, empty. Four stations are enough to pass every rule above: an orientation, a person, an outside counterpoint and something you make.

Why it matters. A route kept in a file outlives this site. You can fork it, print it, or open it in a walker I did not write, and you can check any route page here against the route.json it was built from.

Devil's advocate. The rules check the shape of a claim and not its truth. The audit confirms that a counterpoint names a dated source with an author and an origin other than "generated". It cannot tell whether that source says what the route says it says, or whether "published" is true. A careful liar passes. Checking still takes a person reading the source.

Rabbit hole. Open the second-mapper route's file and find its counterpoint. Then read Legible AI on when a second opinion is really a second opinion.
