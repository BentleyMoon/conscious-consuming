Portable values

Your values, saved as a file you keep

Your file is small, nameless, and yours to keep. It carries your rules and optional close-call priorities so compatible tools can help with choices without making you create an account. The technical format is called an Open Values Passport.

Make yours in the live app Read the file note Find group agreement

Privacy promise

Weights and rules, no identity

It contains your rules and priorities. There is no personal history in it for a platform to profile.

Minimal

Only values travel

Weights, vetoes, and compatibility hints are enough. Identity, history, and tracking IDs stay out.

Owned

Your file, your copy

Keep it on your device, move it by any channel, duplicate it, edit it, or delete it.

Honest

No fake transfer

A tool applies only the values its subject can express, and should show what did not transfer.

Portable

No account required

The file should work across compatible tools and group pages without platform lock-in.

Contents

Enough to rank, not enough to identify

The file carries weights, deal-breakers, and a version. It should not need a name, email, purchase history, location trail, or social graph.
